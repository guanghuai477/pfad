This is a simple maze walking game, running on python 3.12. Please make sure you have the “pygame”, 
“sys” and “time” libraries installed before running the code.


Rules of the game:
Players use “A”, “D”, “S” and “W” keys to control the red dot movement, and go to the exit in the 
lower right corner. You will win the game!


Please note:
1. The game will be closed automatically after winning, please wait 1-2 seconds. 2.
2. The game has sound effects, please lower the volume in advance to ensure that the game will not disturb 
other people.
